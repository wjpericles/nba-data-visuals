# NBA Data Visualization
Repo containing notebooks that generates visualizations for NBA data obtained from the nba_api library.

## 2025-2026 Season
### [2025-26 Team Scoring Differential](https://github.com/wjpericles/nba-data-visuals/blob/main/src/team_season_summary.ipynb)
\- How teams' scoring improved or worsen from the previous season.

### [2025-26 Points per Win](https://github.com/wjpericles/nba-data-visuals/tree/main/src/02_points_per_win)
\- Insights on how teams' offensive performances in victories compared to their overall average.
